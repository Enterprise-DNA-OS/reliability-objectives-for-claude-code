# Why this is a database and commands

The weekly job is to compare measured reliability with a target, check whether the evidence is complete, assign recovery work and record a decision. A query and a written policy are enough for those jobs. The read-only week, coverage and follow-up reports show the same evidence without a running web application.

A monitoring screen gives live charts, fast time-range exploration, streaming updates and convenient on-call interactions. This base has none of those live connections. It works from daily counts and supported exports, without a phone app, offline field capture or drag-and-drop editing. The owner keeps the current monitoring and paging until any custom replacement is tested.

Enterprise DNA can build shared screens, feeds and notification routes around the owned database. Those are separately scoped work, not capabilities implied by a generated snapshot.
