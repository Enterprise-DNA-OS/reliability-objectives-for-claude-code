# Register a service

Run `npm run reliability -- add-service --code=<code> --name=<name> --owner=<owner> --actor=<operator>`. All CLI commands accept `--json`.

The new service remains blocked until its policy and objectives are recorded.

For record changes, use the operator's name in --actor and preview with --dry-run. Do not fabricate measurements, evidence or approvals. Do not send, publish or delete. Report what the command actually returned.
