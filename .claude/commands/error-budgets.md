# Review the error budgets

Run `npm run reliability -- error-budgets`. All CLI commands accept `--json`.

A negative remaining percentage means the budget is exhausted. Missing coverage is unknown, even if the observed percentage looks healthy.

For record changes, use the operator's name in --actor and preview with --dry-run. Do not fabricate measurements, evidence or approvals. Do not send, publish or delete. Report what the command actually returned.
