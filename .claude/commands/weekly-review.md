# Run the Monday reliability review

Run `npm run reliability -- weekly-review`. All CLI commands accept `--json`.

Also run coverage. Lead with blocked decisions, then missing evidence, overdue actions, owner workload and record checks. State where the evidence ends.

For record changes, use the operator's name in --actor and preview with --dry-run. Do not fabricate measurements, evidence or approvals. Do not send, publish or delete. Report what the command actually returned.
