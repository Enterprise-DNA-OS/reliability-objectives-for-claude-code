# Close completed reliability work

Run `npm run reliability -- close-action <action-id> --resolution=<evidence-and-result> --actor=<operator>`. All CLI commands accept `--json`.

Read actions first. Record actual completion evidence. Never mark work complete merely to make a service ready.

For record changes, use the operator's name in --actor and preview with --dry-run. Do not fabricate measurements, evidence or approvals. Do not send, publish or delete. Report what the command actually returned.
