# Assign reliability follow-up

Run `npm run reliability -- add-action --service=<service> --title=<work> --owner=<owner> --due=YYYY-MM-DD --actor=<operator>`. All CLI commands accept `--json`.

Use the operator-supplied work, owner and due date. Record the action without sending a notification.

For record changes, use the operator's name in --actor and preview with --dry-run. Do not fabricate measurements, evidence or approvals. Do not send, publish or delete. Report what the command actually returned.
